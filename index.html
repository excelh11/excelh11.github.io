로봇을 공부하기 위한 가장 처음 해야 하는 세팅

우분투 24.04 설치에서 ROS 2 기초 명령까지, 7편으로 따라 하는 로봇 개발 첫 세팅

7편 Ubuntu 24.04 LTS ROS 2 Jazzy Python · VS Code

시리즈 목차

순서대로 따라 하면 빈 노트북이 로봇 개발 환경이 됩니다.

  1. 00 로봇 공부를 시작하기 전에 알아야 할 우분투·리눅스 기초 운영체제·커널·셸·PATH·sudo·apt가 로봇 개발에서 어디에 쓰이는지, 코드보다 먼저 만나는 벽을 정리합니다. →
  2. 01 우분투 24.04 설치와 첫 세팅 (부팅 USB부터 한글 입력까지) ISO 다운로드, 부팅 USB 제작, BIOS 설정, 설치 마법사 13개 화면을 화면 순서 그대로 따라갑니다. →
  3. 02 파이썬 가상환경(venv) 완벽 정리 — 로봇 프로젝트를 위한 격리 라이브러리 버전 충돌을 막는 venv. 생성·활성화부터 requirements.txt로 재현하기까지. →
  4. 03 VS Code 설치와 파이썬 인터프리터·주피터 커널 연결 ModuleNotFoundError가 반복되는 이유는 편집기가 다른 파이썬을 보고 있기 때문입니다. 정확히 연결하는 법. →
  5. 04 ROS 2 Jazzy 설치 — Ubuntu 24.04에서 talker/listener까지 locale·저장소 준비부터 ros-jazzy-desktop 설치, 두 노드가 메시지를 주고받는 것까지 확인합니다. →
  6. 05 .bashrc로 ROS 2 환경 자동화 + ROS_DOMAIN_ID 격리 매 터미널마다 source를 치지 않도록, 그리고 다른 로봇과 통신이 섞이지 않도록 설정합니다. →
  7. 06 ROS 2 기초 명령 — 터틀심으로 노드·토픽·서비스·액션 익히기 터틀심으로 노드·서비스·토픽·액션을 하나씩 실행하며 ROS 2 통신 구조를 손으로 익힙니다. →
